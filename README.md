# Плагин заметок для VS Code

Расширение для Visual Studio Code, которое добавляет на боковую панель удобный менеджер заметок. Заметки могут быть **общими** (не привязанными ни к чему) или **привязанными к конкретному файлу и строке кода** — по клику такая заметка открывает нужное место в редакторе.

## Возможности

- **Общие заметки** — быстрые заметки «на память», не привязанные к файлам.
- **Заметки к коду** — создаются из контекстного меню редактора (ПКМ) и запоминают файл и строку. Клик по заметке открывает этот файл и позиционирует курсор на нужной строке.
- **Две группы в дереве** — «Общие заметки» и «Заметки в файлах» для наглядной организации.
- **Удаление заметок** — через inline-кнопку рядом с заметкой в списке.
- **Экспорт в JSON** — кнопка на панели выгружает все заметки в отдельный JSON-документ.
- **Сохранение между сессиями** — заметки хранятся в `globalState` расширения и не теряются при перезапуске VS Code.

## Установка

### Из VSIX-файла
1. Соберите пакет (см. раздел «Сборка») или возьмите готовый `.vsix`.
2. В VS Code откройте панель расширений (`Ctrl+Shift+X`).
3. Нажмите `...` → **Install from VSIX...** и выберите файл.

### Для разработки (из исходников)
```bash
git clone https://github.com/vishka-vinka/labwork3_isrpo.git
cd labwork3_isrpo
npm install
npm run compile
```

## Использование
После установки на панели активности слева появится иконка «Мои заметки».

#### Добавить общую заметку
Откройте панель поиска в редакторе.
Введите символ ">" и выберите команду «Добавить общую заметку».
Введите текст и подтвердите (нажатием Enter) — заметка появится в группе «Общие заметки».

#### Добавить заметку к коду
Поставьте курсор на нужную строку в редакторе.
Кликните правой кнопкой мыши → «Создать заметку для этого кода».
Введите текст — заметка появится в группе «Заметки в файлах» с подписью имя_файла:номер_строки.
Клик по заметке в списке откроет соответствующий файл на нужной строке.

#### Удалить заметку
Наведите курсор на заметку в списке и нажмите иконку корзины (inline-кнопка).

#### Экспортировать заметки
Нажмите кнопку экспорта в заголовке панели — откроется новый документ с JSON-представлением всех заметок. Его можно сохранить через «Файл → Сохранить как…».

## Функции/команды
#### activate(context)
export function activate(context: vscode.ExtensionContext): void

Активирует расширение при его запуске.
Создает провайдер заметок, регистрирует представление в боковой панели и привязывает команды к событиям.
Параметры:
  context (vscode.ExtensionContext): контекст расширения VS Code для доступа к глобальному хранилищу.
Возвращаемое значение:
  void: функция ничего не возвращает.
#### deactivate()

#### NotesProvider.addNote(note)
public addNote(note: NoteData): void
```
Добавляет новую заметку в список и сохраняет изменения.
Параметры:
  note (NoteData): объект заметки, содержащий текст, тип ('global' или 'file') и опциональные данные о файле и номере строки.
Возвращаемое значение:
  void: функция ничего не возвращает.
```
#### NotesProvider.deleteNote(noteToDelete)
public deleteNote(noteToDelete: NoteData): void
```
Удаляет указанную заметку из списка и сохраняет изменения.
Параметры:
  noteToDelete (NoteData): объект заметки, который нужно удалить.
Возвращаемое значение:
  void: функция ничего не возвращает.
```

#### NotesProvider.getChildren(element?)
public getChildren(element?: any): Thenable<any[]>
```
Возвращает дочерние элементы для отображения в дереве.
Параметры:
  element (any, опционально): родительский элемент дерева. Если не передан, возвращает корневые группы.
Возвращаемое значение:
  Thenable<any[]>: список групп (для корня) или объектов заметок (NoteItem).
```
#### NotesProvider.getTreeItem(element)
public getTreeItem(element: any): vscode.TreeItem
```
Преобразует данные элемента в объект TreeItem для отрисовки в интерфейсе.
Параметры:
  element (any): элемент дерева (NoteItem или группа).
Возвращаемое значение:
  vscode.TreeItem: объект для отображения в интерфейсе VS Code.
```
#### NoteItem.constructor(data
constructor(public readonly data: NoteData)
```
Создает элемент дерева для одной заметки. Настраивает иконку, описание и команду перехода к файлу, если заметка привязана к коду.
Параметры:
  data (NoteData): объект с данными заметки.
Возвращаемое значение:
  экземпляр класса NoteItem.
```
